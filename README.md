# Whisper — офлайн-транскрибация аудио и видео

Локальное приложение: перетащили аудио или видео любого формата — получили текстовую
расшифровку. Всё считается **на вашем компьютере**: ни файлы, ни текст никуда не
отправляются. Интернет нужен только один раз — чтобы скачать модель.

Рассчитано на слабые машины: звук обрабатывается кусками, куски удаляются сразу,
зависшая задача не блокирует очередь.

## Возможности

- **Любой формат.** Расширение не важно — `ffmpeg` определяет содержимое по данным:
  `mp3, wav, m4a, m4b, aac, flac, ogg, opus, wma, amr, aiff, caf, mp4, mov, mkv,
  webm, avi, wmv, mpg, ts, 3gp` и всё остальное, что он умеет читать.
- **Деление записи по паузам.** Небольшая модель (Silero VAD, 2 МБ) находит в записи
  речь и тишину. Куски нарезаются **по паузам, а не по фиксированной минуте** — так
  не обрываются слова на стыках. Поиск пауз в 51-минутной записи занимает ~4 секунды.
- **Тишина не тратит время.** Фрагменты без речи (паузы, выключенный микрофон, музыка)
  не отправляются в распознавание, а шаблонные фразы-галлюцинации («Продолжение
  следует…») отфильтровываются.
- **Словарь терминов и имён.** Свой список правильных слов уходит в подсказку
  распознаванию, а замены («гигел → Гегел») правят уже готовый текст с учётом
  окончаний и регистра. Словарь можно применить и к ранее созданному файлу.
- **Несколько звуковых дорожек.** Если первая дорожка пустая или тихая, берётся
  следующая — частая ситуация в записях OBS и камер.
- **Надёжность.** Журнал задач переживает перезапуск, упавшую задачу можно повторить,
  результат сохраняется только целиком, недописанный файл не выдаётся за готовый.
- **Удобно.** Очередь загрузок с отменой и повтором, переименование готовых файлов,
  оценка оставшегося времени, понятные ошибки на русском, индикатор свободной памяти.

## Требования

- **macOS** (Apple Silicon или Intel) либо **Windows 10/11**.
- `ffmpeg`.
- Свободной памяти: около 1 ГБ на Apple Silicon, около 1.5 ГБ на процессоре.

Распознавание работает на одном из двух движков и выбирается автоматически:

| Платформа | Движок | Как считает |
|---|---|---|
| macOS на Apple Silicon | MLX | на видеокарте — быстро |
| Windows, Linux, Intel-маки | faster-whisper | на процессоре — медленнее |

## Установка

**macOS:**

```bash
brew install ffmpeg
bash setup.sh
```

**Windows** (в PowerShell, один раз):

```powershell
winget install Python.Python.3.12
winget install Gyan.FFmpeg
powershell -ExecutionPolicy Bypass -File setup.ps1
```

Оба скрипта создают окружение `.venv`, ставят нужные библиотеки и **один раз**
скачивают модель распознавания. Дальше интернет не нужен.

## Запуск

- **macOS:** двойной клик по **«Запустить Whisper.command»**.
- **Windows:** двойной клик по **`start.bat`**.

Откроется окно терминала (не закрывайте его — это и есть приложение) и браузер
с интерфейсом. Чтобы выключить, закройте это окно.

> Первый запуск macOS может предупредить о неизвестном разработчике. Тогда:
> правый клик по файлу → «Открыть» → «Открыть».

## Как пользоваться

1. Перетащите файлы в окно браузера (можно пачкой — обработаются по очереди).
2. Необязательно: заполните **подсказку** и **словарь терминов** — это повышает
   точность на именах и специальных словах.
3. Готовые `.txt` лежат в папке `output/`. Оттуда их можно скачать, переименовать
   или показать в проводнике (на macOS — в Finder) прямо из интерфейса.

## Словарь терминов и имён

Формат — одна запись в строке (правится в интерфейсе):

```
# просто слова — как правильно (идут в подсказку распознаванию)
Гегель
фасилитатор
экспедиция

# замены: как слышится → как правильно (указывается основа слова)
гигел → Гегел
фацилитатор → фасилитатор
ликтофон → диктофон
```

Основа слова — значит правило «гигел → Гегел» исправит и «Гигелем», и «Гигеля».
Регистр сохраняется: с маленькой буквы останется с маленькой. Рабочий словарь
хранится в `data/glossary.json` и в репозиторий не попадает.

## Модель распознавания

По умолчанию стоит **сжатая модель `whisper-large-v3-turbo-q4`** (442 МБ вместо
1611 МБ). На реальной 10-минутной записи она заняла **801 МБ памяти против 1334 МБ**
у полной версии и оказалась на 10% быстрее — при сопоставимом качестве.

| Платформа | Модель по умолчанию | Размер |
|---|---|---|
| Apple Silicon (MLX) | `whisper-large-v3-turbo-q4` | 442 МБ |
| Процессор (faster-whisper) | `faster-whisper-large-v3-turbo-ct2` | 1.5 ГБ |

Модель переключается в интерфейсе; недостающие можно докачать там же (это
единственный момент, когда приложению нужен интернет). Если на процессоре
не хватает скорости — выберите в списке модель поменьше.

**Скорость моделей** (замер на реальной русской речи 4:09, процессор, int8):
самая быстрая — tiny (11 с), base ×1.6, small ×4.0, turbo ×4.6 от tiny.
Чем больше модель, тем лучше она распознаёт имена, термины и числа:
на тесте tiny выдал «циклопедии» и «Диабайна», а turbo — «энциклопедии» и
«Аратеус Кипадокийский» (при этом обе версии близки к истине).

## Настройки

Переменные окружения (необязательно):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `WHISPER_MODEL` | из настроек | принудительно задать модель |
| `WHISPER_LANGUAGE` | `ru` | язык распознавания |
| `WHISPER_CHUNK` | `600` | целевой размер куска, секунд |
| `WHISPER_MIN_CHUNK` | `120` | минимальная длина куска |
| `WHISPER_OVERLAP` | `15` | перекрытие кусков |
| `WHISPER_VAD` | `1` | `0` — выключить определение речи |
| `WHISPER_STALL_SECONDS` | `2700` | когда считать задачу зависшей |
| `WHISPER_MAX_UPLOAD_GB` | `64` | максимальный размер файла |
| `WHISPER_NO_BROWSER` | — | `1` — не открывать браузер |
| `WHISPER_ALLOW_NET` | — | `1` — разрешить докачку модели |

## Что внутри

```
whisper-offline-transcriber/
├── start.bat                   запуск двойным кликом (Windows)
├── setup.ps1                   установка окружения (Windows)
├── Запустить Whisper.command   запуск двойным кликом (macOS)
├── setup.sh                    установка окружения (macOS)
├── server.py                   сервер: ffmpeg, VAD, распознавание, очередь задач
├── index.html / style.css / app.js   интерфейс
├── models/silero_vad.onnx      модель определения речи (2 МБ)
├── output/                     готовые транскрипты
└── data/                       словарь, журнал задач, настройки, копии
```

Сервер слушает только `127.0.0.1`, проверяет заголовки `Host` и `Origin`, а результат
отдаёт лишь по внутреннему идентификатору. Наружу приложение не открыто.

## Ограничения

- На Windows и Intel-маках распознавание идёт на процессоре: медленнее, чем на
  Apple Silicon. Если не хватает скорости — выберите модель поменьше в интерфейсе.
- Нет разметки говорящих (кто сказал) и экспорта в SRT/JSON — в планах.
- Таймкоды к концу длинной записи могут «плыть» раньше на 10–15 секунд; для
  цитирования с точностью до минуты этого достаточно.
